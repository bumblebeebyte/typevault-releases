# TypeVault Releases

Downloads und Update-Feed für [TypeVault](https://bumblebeebyte-studio.de/apps/typevault/), die Mac-App, die getippten Text im Arbeitsspeicher aufbewahrt, damit du ihn zurückholen kannst.

- **Download:** [TypeVault.dmg (neueste Version)](https://github.com/bumblebeebyte/typevault-releases/releases/latest/download/TypeVault.dmg) · macOS 14 oder neuer
- **Homebrew:** `brew install bumblebeebyte/apps/typevault`

Die App ist mit Developer ID signiert und von Apple notarisiert. `appcast.xml` ist der Update-Feed für Sparkle.
